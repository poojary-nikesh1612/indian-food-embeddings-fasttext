# Indian Food Embeddings using FastText

This project demonstrates how to train custom word embeddings using FastText on an Indian food recipes dataset.

The workflow includes:
- Text preprocessing using Regular Expressions (Regex)
- Creating a clean training corpus
- Training FastText Skip-Gram model
- Training FastText CBOW model
- Finding nearest word similarities
- Performing word analogies

## Technologies Used

- Python
- Pandas
- FastText
- Regex

## Dataset

Indian food recipes dataset containing translated cooking instructions.
